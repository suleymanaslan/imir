# Sample image

`deraining.png` is a degraded Rain100L test image, provided for the quick-start
inference example. It is copied without modification from test sample
`rain100l/test/low/000025.png`.

Rain100L was introduced by Wenhan Yang et al. in
[Deep Joint Rain Detection and Removal from a Single Image](https://openaccess.thecvf.com/content_cvpr_2017/papers/Yang_Deep_Joint_Rain_CVPR_2017_paper.pdf),
CVPR 2017. Image rights remain with the respective dataset authors and owners.
